#  Deepfake Detection System

A deep learning-based web application built to verify and detect deepfake images and videos using OpenCV, Machine Learning, and Deep Learning, featuring an interactive user interface built with Gradio.

##  Features
•⁠  ⁠Detects manipulated/fake images and videos.
•⁠  ⁠Utilizes computer vision techniques with OpenCV.
•⁠  ⁠Deep learning model integration for classification.
•⁠  ⁠Interactive and user-friendly Gradio chat/web interface.

##  Tech Stack
•⁠  ⁠*Python*
•⁠  ⁠*OpenCV*
•⁠  ⁠*Deep Learning / Machine Learning*
•⁠  ⁠*Gradio*
